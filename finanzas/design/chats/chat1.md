# App Registro Ingresos y Egresos

_Started 2026-09-28 15:29 UTC_

---

## User

Usando este tipo de diseño desarrolla una app para registro de ingresos y egresos, mostrando el monto de la cuenta bancaria en vivo, pantalla principal mostrando el monto de la cuenta bancaria en vivo, además dos botones, uno para registrar ingresos y otro para registrar egresos, si registras un ingreso te lleva a un formulario donde debes rellenar los datos, fecha, permite seleccionar si el ingreso de por obra/proyecto, venta, otro, y se debe digitar el monto que se ingresa, este monto luego se sumará a la cuenta bancaria en vivo, para el egreso te lleva a otra ventana, donde se puede registrar de manera manual o con captura de pantalla, para el ingreso manual te lleva a un formulario, donde se llenan varias cosas, como fecha, persona, descripción, ciudad, categoria aqui es para selección, equipos, cada pizarro, movilidad, material, sueldo, oficina, fletes, viaticos. Para la otra pantalla de "con captura de pantalla" que te permita subir una foto, esta foto es analizada y se obtiene la información de la foto para poder llenar de manera automatica al formulario, al cual te llevará despues de subir la foto, y ya se editara si algun cambio es necesario. En los dos formularios finales antes de registrar el ingreso o egreso, ambos llevan un botón de confirmación para registrar el ingreso o egreso finalmente.
